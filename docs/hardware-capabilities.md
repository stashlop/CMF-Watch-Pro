## Install-ready watch faces (`watch_faces/`)

Generated by `python -m omnitrix.watch_release [--all | --theme <key>]`. These static PNGs are the only part of the Omnitrix project that goes on the watch. The owner installs them as a custom photo face in the official CMF Watch app.

| Property | Value | Why |
|---|---|---|
| Size / format | 410 × 502, 24-bit RGB PNG, no alpha, ~100 KB | Spec-sheet resolution, **pending calibration** |
| Omnitrix dial | Centred at (205, 251), scaled to 76 % | Symbol centred; leaves room for the clock |
| Clock bands kept dark | top y < 119, bottom y > 383 | The app's clock (top or bottom) never overlaps the dial |
| Background | 65 % true-black pixels (home), near-blacks crushed to 0 | AMOLED: unlit pixels look deep black and save power |
| Live data | None baked in; the energy meter is decorative | A photo face can't update |

Status: home + all 10 alien faces generated (home design approved by the owner on 2026-11-07). Alien faces add:
- each alien's emblem in two side badges, because accent colour alone doesn't separate Heatblast/Wildmutt or XLR8/Diamondhead/Ripjaws;
- ambient effects frozen at one moment and faded to 12 % inside the clock bands;
- no slice-glitch post-processing, which reads as a corrupt image when static.

Every face measures ≥ 50 % true black with both clock bands at a mean brightness below 6/255. `tests/test_omnitrix.py` enforces this. Not yet installed or checked on the watch.
The older `data/exports/omnitrix/phone/` pack (top/centre/bottom variants) is superseded by this layout; `calibration.png` there is still the test image to install first.

## Omnitrix features vs. the real watch

| Feature | Desktop prototype | On the watch |
|---|---|---|
| Omnitrix home screen look | Yes | **Yes, as a static photo face.** The app supports custom photo faces. The watch's own template draws the clock over our image (`python -m omnitrix.photoface`) |
| Alien-specific themes | Yes | **Yes, static.** One photo face per alien, switched by hand in the app |
| Alien selection dial (rotate, tap, highlight) | Yes, simulated | **No.** Needs custom apps or touch handling; no supported route known |
| Transformation animation | Yes | **No.** No known way to run custom animations. A GIF export is for sharing and preview only |
| Physical button opens selector | Simulated (B key) | **No.** Button remapping isn't known to be possible |
| Long-press to transform, back gesture | Simulated | **No** |
| Sound effects | Not built | **No.** The speaker is for calls; no known way for faces to play audio |
| Animated energy indicators | Yes | **Unknown** (depends on animation support) |
| Live battery / date on face | Yes (simulated data) | Only if the watch's face template draws them |

## Ground rules this project keeps

- No BLE writes, notification subscriptions, pairing changes, factory reset, shipping mode or firmware flashing.
- The desktop prototype (`omnitrix/`) never imports the BLE package or talks to the watch.
- Anything that would send data to the watch, including a face upload, is a separate phase that needs explicit owner approval first.
- Backup point before this work: git tag `backup/pre-omnitrix`.
